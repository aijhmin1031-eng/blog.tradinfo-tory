## 이 세션의 교훈 (반복 금지)

- 원격 컨테이너의 node fetch는 프록시에 막힘 → 로컬 시드는 curl. CI는 정상.
- data.go.kr는 API별 활용신청 필요(키는 계정당 1개). 관세청 nitemtrade는 품목·국가 중 1개 이상 필수, 첫 item이 총계.
- Pollo 생성물의 글자 깨짐·색 규약 위반은 눈 검수로만 잡힌다 — 시트 만들어 반드시 확인.
- Astro: 인라인 컴포넌트 앞뒤 공백 누수, JSX 속성 내 스프레드·복잡식 컴파일 오류 → frontmatter 사전 계산.
- pkill -f는 자기 자신을 잡을 수 있다(패턴에 [] 이스케이프).
- 소유주 성향: 디테일 지적이 정확하고 기준이 높다. 어중간한 결과물을 보여주지 말고, 기준 미달이면 먼저 기준부터 세울 것.
