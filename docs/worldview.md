# 무역토리 세계관 문서 v1.0

> 이 문서는 무역토리의 브랜드 세계관 확정본이다. 모든 콘텐츠·디자인·모션은 이 문서를 따른다.

## 로그라인

**"거래가 있는 곳에, 토리가 갑니다."**

숲(시장)은 넓고 계절(경기)은 계속 바뀐다. 토리는 겨울(불확실성)에 대비해
좋은 도토리(검증된 데이터)를 모으는 다람쥐 이코노미스트다.
오늘도 거래가 벌어지는 곳으로 출근한다.

## 기원 동화 — 「첫 번째 도토리」

1. 옛날, 사계절이 유난히 변덕스러운 숲이 있었습니다.
2. 그 숲의 다람쥐들은 가을이 오면 서둘러 도토리를 주웠지만, 어떤 도토리가 좋은 도토리인지는 아무도 묻지 않았습니다.
3. 어린 토리는 조금 이상한 다람쥐였습니다 — 도토리를 줍기 전에 꼭 들여다보고, 무게를 재고, 작은 장부에 적었으니까요.
4. "그럴 시간에 하나라도 더 주워!" 이웃들은 웃었습니다.
5. 그해 겨울은 예고 없이 일찍 왔고, 유난히 길었습니다.
6. 서둘러 모은 도토리들은 쪼개 보니 절반이 속이 빈 것이었습니다.
7. 그때 토리가 창고를 열었습니다. 장부에 적힌, 속이 꽉 찬 도토리들이 가지런히 쌓여 있었습니다.
8. 그 겨울, 숲의 모두가 토리의 도토리로 봄을 맞았습니다.
9. 봄이 온 날 토리는 결심했습니다. "좋은 도토리가 어디서 나는지, 매일 다녀와서 알려주자."
10. 그날부터 토리는 거래가 있는 곳이라면 어디든 갑니다 — 그리고 매일 아침, 주워 온 숫자를 브리핑합니다.

*(용도: 소개 페이지에 4컷 카툰과 함께 게재. 애니메이션 스크롤 연출.)*

## 은유 체계

| 세계관 언어 | 실제 의미 | 쓰이는 곳 |
|---|---|---|
| 숲 | 시장·경제 전체 | 소개 페이지, 기사 표현 |
| 도토리 | 검증된 데이터·정보 한 조각 | "오늘 주운 도토리 3알" = 핵심 3가지 |
| 도토리를 줍다 | 공식 데이터를 확인하다 | 브랜드 동사 |
| 속이 빈 도토리 | 출처 없는 소문·추측 | 팩트체크 코너 표현 |
| 겨울 | 경기 침체·불확실성 | 리스크 관련 콘텐츠 |
| 도토리 창고 | 아카이브·지표 대시보드 | 메뉴명 |
| 계절이 바뀐다 | 금리·환율 국면 전환 | 시황 전환 기사의 관용구 |
| 장부 | 데이터 파이프라인·출처 기록 | 출처 표기의 캐릭터화 |

## 토리 프로필

- **직업**: 숲의 이코노미스트. 매일 아침 7시 브리핑.
- **성격**: 숫자 앞에서 냉정, 설명은 다정. 호들갑 금지 — 폭락장에도 "겨울인지, 바람 한 번인지 숫자부터 확인하자".
- **말투**: 차분한 존댓말. 1인칭 "토리". 단정 대신 근거: "~입니다. 근거는 이 차트입니다."
- **외형**: 둥근 안경 + 네이비 베스트·타이 (최종 1 디자인). 꼬리는 절제.
- **디테일 명세 v2 (2026-08-22 고도화)**: 금테 둥근 안경 · 직조 질감의 네이비 베스트 + 황동 단추 2개 · 가슴의 황금 도토리 배지 · 흰 셔츠 칼라 + 짙은 네이비 타이 · 크림색 가슴털 투톤 · 손에 얇은 나무 연필(기록하는 애널리스트의 상징). 신규 이미지는 이 명세의 레퍼런스(스크래치패드 `tori-char/url_p1.txt`, 사이트 원본 `public/images/tori/tori.jpg`)를 기준으로 생성한다.

## 진화하는 토리 — 성장 마일스톤 v1 (2026-08-22 소유주 승인 컨셉)

**원칙**: 실루엣·네이비 베스트·둥근 안경 등 핵심 정체성은 불변. 진화는 블로그의 **실측 지표**가 달성될 때 소품·공간·서사에만 반영한다(검증 가능한 수치 원칙과 세계관의 결합). 각 변화는 적용 전 소유주 승인을 받고, 이 문서에 v3, v4…로 명세를 기록하며, 변화 자체를 공지 콘텐츠(카툰·기사)로 만든다.

| 마일스톤 (실측 지표) | 토리의 변화 | 적용 위치 |
|---|---|---|
| 기사 50편 발행 | 연필 → **만년필** 승급 (기록자의 성장) | 레퍼런스·신규 일러스트 |
| 기사 100편 발행 | 도토리 배지에 **월계 잎** 장식 + 성장 에피소드 카툰 1편 | 배지 디테일 · about 페이지 |
| 특집 2호 개설 | 서재에 **두 번째 책장**(특집 서가) 등장 | 일상이야기 배경 |
| 커스텀 도메인 연결 | 베스트에 **회중시계** 소품 (자기 이름의 시간) | 신규 일러스트 |
| 애드센스 승인 | **창고 증축** 일러스트 (선반 확장) | 도토리 창고 페이지 |
| 일 방문 1,000 도달 | 조수 캐릭터 도입 검토 (별도 기획·승인) | 세계관 확장 |

## 카툰 연작 편성 규칙 (2026-08-22 소유주 지시)

**공통 원칙**
1. **충분히 길게, 스토리가 있게** — 기·승·전·결이 있는 서사(표준 10~16컷). 정보 나열형 짧은 컷 금지. (예외: 제1화 「새벽의 장부」는 4컷 파일럿으로 유지)
2. **인용되는 장면을 심는다** — 화마다 방문자가 캡처·인용하고 싶어질 결정적 장면과 대사를 최소 1개 설계한다(토리의 경구, 반전 컷, 상징적 이미지). 인용구는 격식체 경구로 다듬는다.
3. 무자막 이미지 + HTML 말풍선(about.astro 방식), v2+ 레퍼런스로 캐릭터 일관성 유지, 전 컷 눈 검수.
4. 게재는 about(토리 이야기) 페이지 연작 섹션. 세계관 확장(새 공간·소품·인물)은 카툰으로 공개하는 것을 정식 절차로 한다.

**연작 1 — 「토리의 일상」**: 슬라이스 오브 라이프. 마일스톤·계절 이벤트와 연동(마일스톤 달성 = 새 에피소드).
제1화 「새벽의 장부」(4컷 파일럿, 2026-08-22). 제2화 「만년필」(12컷) — 기사 50편 달성 시 자동 공개(about.astro 발행 수 게이트).

**연작 2 — 「토리의 갈림길」**: 월간 전망 카툰. 매월 초(수출입 통계 발표 후) 발행.
구성 규칙: ① 현재 좌표(실측 수치) ② 갈림길 A/B(조건부 시나리오 — "이 지표가 이렇게 되면 이 길", 단정 예측 금지) ③ 각 갈래의 확인 지표 명시 ④ **지난 화 성적표**(어느 길이 실제로 열렸는지 공개 채점 — 이 연작의 신뢰 자산). 철칙 준수: 도토리를 대신 골라주지 않는다·겨울을 팔지 않는다.
제1화 예정: 2026-10-01 「반도체 단가의 갈림길」 — 좌표: kg당 19,479달러(26.7월), 갈림길 A: 8~9월 단가 상승 지속 → 사이클 연장 신호(확인: 관세청 월별 단가), 갈림길 B: 단가 정체·하락 → 변곡 경계(확인: 단가+장비 수입+주가 3신호 동반 여부).
- **철칙**: ① 주운 도토리만 말한다(무출처 금지) ② 도토리를 대신 골라주지 않는다(투자 조언 아님) ③ 겨울을 팔지 않는다(공포 조장 금지)

## 독자와의 관계

- **호칭 없음.** "구독자님", "여러분", "이웃님" 등 독자 호칭을 쓰지 않는다.
  문장은 정보와 토리 자신을 주어로 쓴다. (예: "오늘 확인한 숫자는 셋입니다.")

## 금지 목록 (전문가 톤 방어선)

- 유아적 어미("~해요 뿅"), 과도한 의성어, 이모지 남발
- 근거 없는 단정·전망, 공포/욕망 자극 헤드라인("폭락 온다", "무조건 사라")
- 도토리 은유의 남용 — 한 기사에 세계관 표현은 2~3회 이내
