## app-icon-128.png 를 다시 만드는 법

`public/favicon.svg` 의 도토리 마크에 크림 바탕(`#F7F4EE`)을 깔아 128px 정사각으로 구웠다.
투명 배경을 그대로 올리면 흰 바탕 서비스에서 마크가 떠 보이고, 어두운 목록에서는 사라진다.
바탕을 깔면 어느 자리에서도 같은 모양으로 선다.

Playwright 로 SVG 를 그려 잘라 낸다(이 컨테이너에는 래스터라이저가 없다).
`.b` 상자를 128×128 로 두고 마크를 86×100 으로 가운데 놓은 뒤 그 상자만 스크린샷하면 된다.
색은 깍정이 `#5C3A22` · 열매 `#B4552D` 로 브랜드 규약 그대로다.
